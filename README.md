# TROVIORA — U.S. city discovery

This branch hosts the independently published TROVIORA static site at https://troviora.com, deployed automatically on Render as service `troviora`.

- 12 city guides, 36 places, 50-state filter
- Responsive photography sourced from Wikimedia Commons with photo-credits page linking authors, licenses and originals
- Accessible saved-place browser-local shortlist, city filters, editorial discovery and mobile navigation
- SEO-friendly prerendered HTML with unique canonical URLs, structured city data and sitemap at `/sitemap.xml`
- No tracking scripts, payment processing or subscriptions in this version

Only update branch `troviora-static`; leave branch `main` (ZAYVERO) untouched. Photos remain externally hosted on Wikimedia Commons and may require refreshing if sources change.
